Why these sections?

Core contains the shared config, rules, theme and localization. Feature owns structure and composition. UI & State owns presentation and screen behavior. Data and DB distinguish application contracts from storage mechanics.

How work crosses sections

Design uses Core, Feature and UI guidance to build a screen. Test checks behavior, design fidelity and saved visual baselines. Lines indicate grouping; sections are not a required execution order.
